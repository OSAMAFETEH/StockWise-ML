# StockWise ML

**Demand Forecasting and Inventory Risk Prioritization for Small Retailers**

## Overview

StockWise ML is a machine learning decision-support project designed to help small retailers analyze historical product demand, forecast future sales, segment products by sales behavior, and prioritize potential inventory risks under configurable stock scenarios.

## Objectives

- Forecast product demand using classical machine learning algorithms.
- Compare Linear Regression, Decision Tree, and Random Forest.
- Segment products using K-Means clustering.
- Estimate inventory risk under explicitly defined stock and supplier lead-time assumptions.
- Build an interactive dashboard for exploring forecasts and risk rankings.

## Dataset

The project uses the UCI Online Retail dataset.

Source: https://archive.ics.uci.edu/dataset/352/online+retail

The dataset contains historical transactions, not actual inventory balances or supplier lead times. Inventory risk outputs will therefore be scenario-based estimates, not verified historical stockout events.
